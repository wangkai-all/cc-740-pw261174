# 序贯抽检应用（Sequential Acceptance Sampling）

一批货分多次送检，每看一轮结果就决定**接受 / 拒收 / 继续采样**，不沿用固定
样本量的合格线。本应用从空项目构建，纯 Python 标准库实现，无第三方依赖，
计算、状态机与审计明细三者通过同一套事件日志保持一致。

## 判定方法（参数与适用假设随批次保存）

| 方法 | 抽样方式 | 统计量 | 保证 |
|------|----------|--------|------|
| `sprt_binomial` | 有放回 / 大批量 | 二项对数似然比（Wald SPRT） | 实际误拒 ≤ α/(1−β)，误受 ≤ β/(1−α) |
| `sprt_hypergeometric` | 无放回有限批 N | 超几何对数似然比 | 同上，且精确利用批次耗减，N 件满批必判定 |
| `cs_beta_mixture` | 有放回 | Beta(1,1) 混合**置信序列**（Ville 不等式） | 时齐覆盖 ≥ 1−α_cs，任意停止时刻有效 |

- 方案在批次创建时整体快照进事件日志，事后修改预置配置不影响历史判定。
- 置信序列用顺序预测混合的似然比鞅 `N_n = m_n / L_n(p)`，其中
  `m_n = k!(n−k)!/(n+1)!`；`E[N]=1`（测试在对数空间数值核验），
  置信集为鞅的上尾反演，随 n 嵌套收窄。该构造偏保守：处于 p0/p1 之间的
  中性批次可能在容量内不判定（以"截尾 continue"返回，绝不强行下结论）。

## 状态机与审计

事件日志（`events`）是唯一事实来源，所有派生状态都由 `state.rebuild`
重放得到。重放是一道强制一致性闸门，会逐项重算 LLR 增量、决策快照并拒绝
任何被篡改的日志。

- **重复件不重复计信息**：同一件号再次送检记入 `duplicate_blocked`，不改变
  (n, k)；同批内重复同样拦截。
- **有放回 vs 无放回分别计算**：二项 SPRT 用 iid 闭式 LLR；超几何 SPRT 用
  依赖剩余批次构成的逐步似然比，撤回后必须整体重算。
- **误归撤回**：未判定或已判定未放行时，撤回该件并从存活样本重建到受影响前
  的决策状态（旧判定标记为 `supersedes_decision`）。
- **放行后不可改写**：已放行批次的撤回转为 `correction_flagged` 后续更正，
  统计量与历史放行时间保持不变，重复放行直接报错。

## 目录结构

```
app/
  stats.py       三种判定引擎、边界、投影、置信序列求根（纯函数）
  state.py       仅追加事件日志 + 重放状态机（接受/拒收/继续）
  storage.py     原子 JSON 持久化、JSONL 全局审计流、固定风险预置
  simulate.py    可复现虚构货物模拟（同种子配对，直驱事件日志后过一次重放闸门）
  handcheck.py   手算轨迹核对：逐步累加 vs 闭式 vs 引擎逐轮比对
  server.py      stdlib HTTP API + 静态网页
web/             单页前端：逐轮收样、查看边界、撤回、配置比较、实验、审计
tests/           59 个 unittest（统计、状态机、存储、模拟、覆盖率保证）
experiments/     可复现实验 CLI 与样例报告
requirements.txt 零第三方依赖声明（仅需 Python 3.11 标准库）
```

## 运行

```bash
# 启动网页/API（默认 http://127.0.0.1:8000，数据目录 ./data）
python3 -m app.server --data-dir data --port 8000

# 全部测试
python3 -m unittest discover -s tests

# 手算轨迹核对（JSON 报告，all_match 必须为 true）
python3 -m app.handcheck

# 可复现实验：错误放行风险 + 平均检验量，跨固定风险配置配对比较
python3 -m experiments.run_experiment --replications 200 --cap 1500 \
    --out experiments/sample_report.json
```

## 网页功能

- **批次与逐轮收样**：每行 `件号,合格/不合格` 录入一轮；显示当前 LLR/置信
  区间、Wald 边界、下一轮抽样投影（全合格/全不合格各自最少再检几件）。
- **撤回误归样本**：填原因后撤销该件贡献并恢复决策状态；放行后只追加更正。
- **风险配置**：查看五套预置（严格/标准/宽松/无放回有限批/置信序列），
  也可校验保存自定义方案，假设文本随方案返回。
- **可复现实验**：固定种子下让各配置检验相同虚构货物，比较接受率、拒收率、
  截尾率与平均检验量（ASN）。
- **手算核对 / 审计流**：一键核对逐轮统计量；查看仅追加的 JSONL 审计明细。

## 一致性如何保证

1. 统计引擎全部为 `(plan, n, k)` 的纯函数，同输入恒同输出。
2. 状态机只追加事件；`rebuild` 重放时重算每个增量并与日志存储值比对，
   篡改 `llr_increment` 或决策快照会立即抛 `StateError`。
3. 模拟器生成的事件日志最终也经过同一个 `rebuild` 闸门（测试断言通过），
   因此实验报告描述的就是应用真实行为，而非另一套实现。
4. 持久化采用临时文件 + 原子 `os.replace`，存储前强制重放，落盘即一致。
